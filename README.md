# Academic Risk Assessment Using Python

A Python data analysis and machine learning project
focused on assessing academic performance and risk.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis and visualization
- Decision Tree classification
- Model analysis and results

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Files
The academic_risk_outputs directory contains
the Python implementation, generated visualizations,
and analysis results.
